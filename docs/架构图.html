可选：将 AI 推理层卸载到第二台算力机
业务层与推理层通过 HTTP 解耦。需要 GPU / 大内存等专用算力时，可把整个 AI 推理层（向量编码 + 向量检索 + 图像分析）迁移到第二台机器（如 dgx-spark），业务层只需修改推理服务地址，无需改动代码。

向量编码 + 向量检索 + 图像分析
与主机器中的 AI 推理层为同一套服务，仅部署位置不同
默认路径：单机一体部署，业务层与 AI 推理层同机运行，本地 SQLite 直接读写，开箱即用。
扩展路径：AI 推理层可整体迁移至第二台算力机，通过 HTTP（:8100）与业务层通信；业务层零改动，仅需配置推理服务地址（INFERENCE_SERVICE_URL）。
