# SmartImageFinder 项目设计指南

## 项目概述

SmartImageFinder 是一个基于 Jina CLIP V2 模型的个人智能图片管理与检索系统。该系统集成 FastAPI、SQLite（含 sqlite-vec 向量搜索扩展）和 React + Ant Design 前端框架，并结合多模态模型 API（如硅基流动），提供全面的图片智能管理解决方案。

**核心定位**：本系统专为个人本地桌面Web应用场景设计，优先保障功能完整性与用户易用性，而非追求极致的性能扩展或复杂的网络优化。

### 核心功能

**通用特性**：所有检索模式均支持基于图片上传时间的范围查询过滤。此外，系统提供基于标签的分类管理和元数据管理功能。

系统支持以下主要功能模块：

#### 1. 检索模式

系统提供两种主要的检索方式：

##### a. 非向量检索模式

- **机制**：基于传统文本匹配。
- **应用**：支持对图片自定义标题和描述进行精确或模糊匹配，适用于关键词精确查找。
- **适用场景**：精确查找。

##### b. 向量检索模式

- **文本-图片匹配**：用户输入文本，系统将其转换为向量，与图片标题/描述向量或图片视觉向量进行相似度计算。
- **文本-文本匹配**：用户输入文本，系统将其转换为向量，与图片标题/描述的文本向量进行语义相似度匹配。
- **图片-图片匹配**：用户上传参考图片，系统将其转换为向量，与库中图片进行相似度匹配。
- **技术实现**：
  - 基于 `sqlite-vec` 扩展实现高效的向量近邻搜索与过滤。
  - 利用 Jina CLIP V2 多模态模型实现文本与图片的语义对齐。
- **向量存储**：
  - 所有向量及其元数据统一存储于 SQLite 的专用向量表 (`title_vectors`, `description_vectors`, `image_vectors`)。
  - 通过 `images` 表的 `id` (在向量表中为 `image_id`) 关联图片及其向量数据。

#### 2. 图片管理

- **界面**：提供专门的图片浏览和管理页面，采用网格式布局，每个图片以卡片形式呈现。
- **图片卡片**：包含图片预览（原图）、基本信息（标题、上传日期等）及快捷操作按钮（编辑、放大、以图搜图、删除）。
- **核心操作**：
  - 支持图片详情查看、批量操作、按标签分类整理。
  - 提供图片信息编辑功能（标题、描述、标签及其他元数据；其中标题、描述、标签本身也是元数据）。
  - 点击“以图搜图”可直接以当前图片为基础进行相似图片搜索。
- **交互式标签筛选**：
  - 页面展示所有可用标签，点击标签可“点亮”并筛选包含该标签的图片。
  - 支持多标签选择以实现组合筛选。
  - 显示各标签对应的图片数量统计。
  - 提供标签快速取消和全部清除选项。
  - 标签筛选可与时间等其他检索条件组合使用。
- **图片加载策略**：
  - 利用 Ant Design 的 `Image` 组件实现懒加载和渐进式加载。
  - 图片浏览采用虚拟滚动技术，优化大量图片浏览时的流畅性。
  - **优化说明**：针对本地使用场景，无需生成和管理缩略图，优先保证功能实现。

#### 3. 图片上传与处理

- **上传方式**：
  - 拖放上传多个图片文件。
  - 文件选择器批量选择上传。
  - 本地文件路径导入。
- **批量处理**：
  - 提供“AI批量异步并发分析”按钮，一键处理所有上传图片，并在后端支持批处理提升处理速度。
  - 后台异步处理，显示进度条和完成状态。
- **个性化处理**：
  - 每个图片容器提供独立的“AI分析”按钮，可单独分析。
  - 智能生成三个默认元数据：图片标题、图片描述、图片标签。
  - 支持为每个图片单独添加自定义元数据字段和值。
  - 提供直观的元数据编辑界面（添加、修改、删除）。
- **上传预览与编辑**：
  - 使用 Ant Design `Upload` 组件实现前端预览。
  - 允许在上传前调整图片元数据。
  - 提供批量标签应用功能。
- **状态跟踪**：
  - 显示每张图片的处理状态和进度。
  - 提供失败重试和取消上传选项。
  - 完成后显示成功/失败统计和摘要信息。
- **数据入库流程**：
    1. 图片文件保存至文件系统（根据日期组织目录）。
    2. 计算图片相关的向量 (`title_vectors`, `description_vectors`, `image_vectors`) 并同步存储至数据库。
    3. 调用多模态内容生成模块生成元数据（标题、描述、标签）。
    4. 图片信息和元数据统一存入 SQLite 数据库，并保持向量与图片的关联。

#### 4. 系统管理与配置

- **状态监控**：
  - 提供系统状态查看页面，展示数据库连接状态、存储情况等关键指标。
  - 显示向量模型加载状态和缓存使用情况。
  - 监控 API 连接状态和关键组件可用性。
- **配置管理**：
  - 允许用户修改系统关键配置（如 API 密钥、服务器设置）。
  - 支持调整存储路径和缓存大小限制。
  - 提供模型选择和配置选项。
- **缓存管理**：
  - 支持清理文本向量和图像向量缓存。
  - 显示当前缓存使用状态和大小。
  - 提供缓存优化选项。

#### 5. 图片存储与文件管理

- **命名策略**：
  - 为每张上传图片自动生成 UUID 作为唯一文件名，防止冲突。
  - 保留原始文件名作为元数据，便于检索和显示。
- **访问优化**：
  - 本地文件系统直接访问，无需复杂网络传输优化。
  - 利用 Ant Design 图片组件进行前端优化（懒加载、渐进式加载）。
  - 使用虚拟滚动技术优化大量图片浏览性能。
- **元数据关联**：
  - SQLite 中通过 `images` 表的 `id` 字段关联图片文件、元数据及向量数据。
  - 存储原始文件名、文件类型、大小等基本信息。
  - 记录图片在文件系统中的相对路径。
  - 同时存储图片向量和文本向量，支持多种相似度查询。

#### 6. 图片元数据辅助生成

- **多模态内容生成**：
  - 基于兼容 OpenAI 格式的多模态模型 API（如硅基流动、书生浦语、智谱清言等）自动为图片生成：
    - **智能标题**：根据图片内容创建描述性标题。
    - **详细描述**：生成对图片内容的全面、准确描述。
    - **语义标签**：提取图片中的关键元素作为分类标签。
  - 支持批量处理，可对新导入图片自动应用内容生成。
  - 用户可编辑调整生成的内容。
  - 支持多语言内容生成。
  - 使用以下优化提示词引导模型生成高质量内容：

    ```python
    DESCRIPTION_PROMPT = """
    请分析这张图片并生成一个10字以内的标题、50字以内的图片描述和5个关键标签，使用JSON格式输出。

    分析以下方面:
    1. 图像类型（图表、示意图、照片等）
    2. 主要内容/主题
    3. 包含的关键信息点
    4. 图像的可能用途

    输出格式必须严格为:
    {
      "title": "简洁标题(10字以内)",
      "description": "详细描述(50字以内)",
      "tags": ["标签1", "标签2", "标签3", "标签4", "标签5"]
    }

    只返回JSON，不要有其他说明文字。
    """
    ```

#### 7. 搜索功能增强

- **组合搜索**：
  - 支持多种搜索方式的灵活组合（文本匹配、向量搜索、混合搜索）。
  - 针对不同搜索模式提供专用的权重调整功能。
  - 实现文本、标题、描述、图像的多维度匹配。
- **相似度分数计算**：
  - 为搜索结果提供标准化的相似度分数（0-1范围）。
  - 基于向量余弦距离和文本匹配强度综合计算。
  - 支持多向量类型的权重组合评分。
- **高级过滤与排序**：
  - 支持标签、时间等多维度过滤条件。
  - 提供基于相似度、时间、文件大小等多种排序方式。
  - 实现过滤条件与搜索方式的灵活组合。
